Quickly share your Socialfy Agenda meeting links with Raycast. Requires [Raycast.com](https://www.raycast.com/) to be installed and the Socialfy Agenda from the Raycast Store needs to be installed: https://www.raycast.com/cal/. You can create an API token in your Developer Socialfy Agenda Settings, and then you can add the API Key by opening up the Socialfy Agenda App in Raycast.
